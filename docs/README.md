# docs/

Public documentation for this repo — committed to GitHub. `docs_sensitive/`
at the project root holds anything that shouldn't go there: actual
secrets/personal material, but also mood boards, design references, or
other heavy/draft assets you don't want bloating the repo's history.

> **`docs_sensitive/` exists locally on this machine but is not in this
> repo** (gitignored). On a different machine or a fresh clone, that
> folder won't be here — check the other machine or wherever else you
> keep it before assuming the content is gone.
